# MC-MCP

Let AI assistants build and play in Minecraft through the Model Context Protocol.

- **God mode**: perceive the world, place/fill blocks, run build scripts, rotate and reuse
  blueprints, preview with fake blocks, take screenshots, and undo anything (optional WorldEdit
  patterns and schematics).
- **Survival mode**: a fake player that walks, mines, gathers, crafts and builds by hand.

Minecraft 1.21.1 · Fabric · Rust MCP bridge.
